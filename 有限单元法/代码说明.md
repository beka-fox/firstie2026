## 五、单元刚度矩阵（第 43～58 行）

```python
def bar_element_stiffness(E, A, L):
    k_factor = E * A / L
    Ke = k_factor * np.array([[1.0, -1.0],
                              [-1.0, 1.0]])
    return Ke

Ke = bar_element_stiffness(E, A, L)
```

- **def 函数名(参数):** 是在**定义一个函数**——把一段计算打包成一个名字，以后可以反复用。
- **bar_element_stiffness(E, A, L)**：函数名是“杆单元刚度”，需要传入弹性模量 E、截面积 A、长度 L。
- 里面先算 **k_factor = E×A/L**，再乘上一个固定的 2×2 矩阵，得到**单元刚度矩阵 Ke**。
- **return Ke**：把算好的 Ke 作为结果“还回去”。
- 下面 **Ke = bar_element_stiffness(E, A, L)** 就是**调用**这个函数，把得到的矩阵存到变量 **Ke** 里。
- **np.array([[...], [...]])** 表示一个**二维数组（矩阵）**。

## 六、总体刚度矩阵（第 60～68 行）

```python
K_global = np.zeros((n_node, n_node))
K_global[0:2, 0:2] += Ke
```

### 6.1 为什么先写 `K_global = np.zeros((n_node, n_node))`？

- **总体刚度矩阵**要容纳**所有节点**之间的刚度，行、列都按“节点编号”来排。
- 这里 `n_node = 2`，所以是 2×2 的矩阵。
- **np.zeros((n_node, n_node))** 的意思是：先做一个 2×2 的矩阵，里面**全是 0**，当作一个“空壳子”。
- 后面再把每个单元算出来的 **Ke** 填进去（或加进去）。这样写的好处是：以后如果有很多单元，只要**对每个单元**把它的 Ke 加到 K_global 的对应位置即可，不用改整体结构。

### 6.2 `0:2` 是什么意思？（Python 的“切片”）

- 在 Python 里，**下标从 0 开始数**：第 1 个是 0，第 2 个是 1。
- **0:2** 叫**切片**，表示：**从下标 0 开始，到下标 2 之前结束**，也就是只包含下标 **0 和 1**（不包含 2）。
- 所以：
  - **行 0:2** = 第 1 行、第 2 行（下标 0 和 1）
  - **列 0:2** = 第 1 列、第 2 列（下标 0 和 1）
- **K_global[0:2, 0:2]** 就表示：这个 2×2 矩阵的**左上角那一块**，也就是**整块**（因为一共就 2×2）。

可以记成：


| 写法    | 含义                 |
| ----- | ------------------ |
| `0`   | 第 1 个（只有这一个）       |
| `1`   | 第 2 个              |
| `0:2` | 第 1 个到第 2 个（共 2 个） |
| `0:3` | 第 1 个到第 3 个（共 3 个） |


### 6.3 这两行合在一起在做什么？

1. **K_global = np.zeros((n_node, n_node))**
  先做出 2×2 的全零矩阵：
2. **K_global[0:2, 0:2] += Ke**
  - 把 **Ke**（单元刚度矩阵）**加**到 K_global 的 **第 0～1 行、第 0～1 列** 这一块。
  - 因为我们现在只有 1 个单元，连接的是节点 0 和节点 1，所以这个单元的 Ke 就填在“行 0、1 和列 0、1”的位置，也就是整块 2×2。
  - 加完之后，K_global 就等于 Ke（因为原来全是 0）。

如果以后有 2 个单元、3 个节点，第二个单元的 Ke 会加在 K_global 的“第 1、2 行，第 1、2 列”那一块，也就是 **K_global[1:3, 1:3] += Ke2**，道理是一样的：**单元连哪两个节点，就加到哪两行、哪两列**。

## 七、荷载向量（第 70～74 行）

```python
F_global = np.zeros(n_node)
F_global[1] = F_right
```

- **F_global**：一个长度为 2 的向量，表示两个节点上的“力”。
- 一开始全是 0；**F_global[1] = F_right** 表示**第 2 个节点（编号 1）**上施加的力是 **F_right = 2**，第一个节点（编号 0）力为 0（左端固定端由支座反力平衡，我们只写已知外力）。

---

## 八、边界条件与求解位移（第 76～90 行）

```python
fixed_dof = [0]      # 第 0 个自由度固定（左端位移=0）
free_dof = [1]       # 第 1 个自由度未知（右端位移待求）

K_reduced = K_global[np.ix_(free_dof, free_dof)]
F_reduced = F_global[free_dof].copy()

u_reduced = np.linalg.solve(K_reduced, F_reduced)

U = np.zeros(n_node)
U[fixed_dof] = 0.0
U[free_dof] = u_reduced
```

- **边界条件**：左端固定 → 第 0 个位移 = 0；只需求第 1 个位移。
- **K_reduced**：从总体刚度矩阵里只取出“和自由位移有关”的那一行一列，这里就是 1×1（因为只有一个未知位移）。
- **F_reduced**：对应的已知力，这里就是右端的 2。
- **np.linalg.solve(K_reduced, F_reduced)**：解方程 **K_reduced × u = F_reduced**，得到未知位移 **u_reduced**。
- 最后把**已知的 0** 和**算出来的 u_reduced** 拼成完整位移向量 **U**：U[0]=0，U[1]=算出来的值（0.006）。

## 小结：程序流程

1. 设置字体，方便图里显示中文。
2. 给出杆长、弹性模量、截面积、右端力、单元数。
3. 算单元刚度矩阵 Ke，再得到总体刚度矩阵 K 和荷载向量 F。
4. 代入边界条件（左端位移=0），只对未知位移求解，得到 U。
5. 在终端打印位移和理论校核。
6. 用变形前后坐标画两个子图（一个放大、一个真实比例），保存为 **bar_deformation.png**。

你以后要改的，多半是：**第 35～40 行的参数**（L、E、A、F_right、n_elem）和**图里的文字**（set_xlabel、set_title、label 等）；其它部分是“固定套路”，理解一次即可。
